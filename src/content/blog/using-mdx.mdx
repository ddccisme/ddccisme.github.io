本铺所有货物（文章）用 Markdown 包装，偶尔用 MDX 加点特殊包装。
这篇是写作速查，忘了语法就回来看一眼。

## 基础包装

**强调**：`**加粗**`、`*斜体*`、`` `行内代码` ``、~~删除线~~

**标题**：`## 二级`、`### 三级`（文章大标题由 frontmatter 的 title 提供，正文从二级开始）

**引用**（适合金句和「一句话记忆」）：

> 每天打烊前，往货架上添一件新货。

**列表**：

- 无序列表项
- 另一项
  - 嵌套项

1. 有序列表
2. 第二项

**表格**（对比类知识首选）：

| 概念 | 一句话 |
| ---- | ------ |
| OLTP | 收银台，要快 |
| OLAP | 账房，要算得清 |

**代码块**（指定语言有高亮）：

```sql
SELECT customer_id, SUM(amount) AS total
FROM orders
WHERE dt >= '2026-01-01'
GROUP BY customer_id
ORDER BY total DESC
LIMIT 10;
```

## frontmatter（每篇文章的「货物标签」）

```yaml
---
title: '文章标题'
description: '一句话摘要，会显示在列表和搜索引擎里'
pubDate: '2026-10-25'
tags: ['大数据', '售前手艺']   # 从既有分区里选：大数据/AI工程/售前手艺/工具杂货/随笔
---
```

## MDX 特殊包装

本铺支持 MDX——可以在文章里直接用 JSX 表达式，比如动态内容：

{/* MDX 注释长这样，不会渲染出来 */}

2 + 2 = {2 + 2}，今年的年份是 {new Date().getFullYear()}。

MDX 文件（`.mdx` 后缀）还可以 import Astro/React 组件，
需要交互图表的时候再翻官方文档：[Astro MDX 指南](https://docs.astro.build/zh-cn/guides/integrations-guide/mdx/)。

## 写作心法

1. **一篇只讲一件事**——讲不清说明还没想清楚
2. **先给结论再给论证**——售前习惯：先说答案，再展开
3. **能用表格就不用段落**——对比类知识用表格，记忆成本减半
4. **结尾留一句「一句话记忆」**——方便未来的自己快速回货
